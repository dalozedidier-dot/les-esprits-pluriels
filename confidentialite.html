Données et vie privée

Confidentialité

Cette page décrit les traitements visibles dans la version actuelle du site. Elle sera complétée avant l’ouverture d’un formulaire, d’un canal de témoignage ou de tout autre service impliquant de nouvelles données personnelles.

Collecte actuelle

Le site ne propose actuellement ni formulaire de contact, ni création de compte, ni espace de connexion. Aucun outil de mesure d’audience, de régie publicitaire ou de ciblage marketing n’est intégré au code de cette version.

Hébergement et journaux techniques

Le site est publié avec GitHub Pages, service d’hébergement statique de GitHub. La documentation officielle de GitHub indique que l’adresse IP des visiteurs d’un site GitHub Pages est enregistrée et conservée à des fins de sécurité, que le visiteur soit connecté ou non à GitHub.

Polices externes

Montserrat et Playfair Display sont actuellement chargées depuis Google Fonts. Le navigateur contacte donc ce service pour récupérer les fichiers de police. Une future version pourra les auto-héberger afin de réduire cette dépendance externe.

Droits prévus par le RGPD

Le RGPD prévoit notamment des droits d’accès, de rectification, d’effacement, de limitation, d’opposition et, lorsque les conditions sont réunies, de portabilité. Une personne peut également introduire une réclamation auprès de l’Autorité de protection des données.

L’adresse publique permettant d’exercer ces droits auprès de Les Esprits Pluriels n’est pas encore définie. Cette page restera incomplète sur ce point jusqu’à la publication d’un contact réel.

Évolutions futures

L’ajout d’un formulaire de contribution, d’une newsletter, d’un outil d’analyse ou d’un autre service impliquant des données personnelles nécessitera une mise à jour de cette page avant sa mise en service.
